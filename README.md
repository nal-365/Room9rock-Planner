# 방구석 작업실 · 올인원 플래너

일간 시간표 · 주간 목표 · 월간 리뷰 · 장부 · 콘텐츠 수익을 **한 장**에 담은 단일 HTML 플래너입니다.
빌드 도구 없이 `index.html` 하나로 동작하고, GitHub Pages에서 바로 열 수 있습니다.

> 🔗 https://nal-365.github.io/Room9rock-Planner/

## 무엇이 되나요

- **일간** — 10분 단위 24시간 타임트래커에 형광펜으로 시간을 칠하고, 할 일(일·공부·집안일)과 날씨·한 줄 메모를 적습니다. **작업** 열은 상태·플랫폼·할 일·여러 줄 상세 내역이 붙은 **카드**로 적고, 플랫폼(카카오·OGQ·스마트스토어 등)은 직접 추가·이름 변경·삭제할 수 있습니다. 작업·자기개발·일정·장부·여가 시간 열 아래에는 하루를 돌아보는 **피드백** 칸이 있습니다.
- **주간** — 다이어리 인덱스 탭 5종(**할 일 · 건강 · 타임테이블 · 장부 · 여가시간**)으로 한 주를 한눈에 모아 봅니다. 일간과 같은 **파스텔 외곽 프레임 + 한 장의 흰 연결 보드**(점선 세로 구분선, 요일마다 파스텔 필 머리글, 오늘 강조)로 7열이 이어집니다. **할 일 카드는 끌어서 다른 요일로 옮길 수 있고**(마우스·아이패드 터치·애플펜슬), 요일 머리글을 누르면 그 날 일간 화면으로 넘어갑니다. 이번 주 목표·리뷰와 요일별 시간 합계도 함께 있습니다.
- **월간** — 달력 위에 하루 요약과 소비, 월 목표·리뷰.
- **장부** — 날짜·분류·시간·내용·금액을 적으면 합계와 분류별 통계가 자동으로 나옵니다. 표는 **날짜 · 카테고리 · 시간 · 내역 · 금액 · 지출/수입** 순서이고, 일간 장부 열과 주간 장부 탭은 한 건을 **1줄 장부카테고리·수입/지출 · 2줄 시간·내역·금액 · 3줄 상세 내역** 카드로 보여 줍니다. 상단 **표 | 달력**으로 보기를 바꾸면 한 달 지출(−빨강)·수입(+초록)과 그날 가장 큰 내역 1줄을 달력 한 장으로 모아 보고, 날짜 칸을 누르면 그날 일간으로 넘어갑니다.
- **콘텐츠** — 이모티콘·스티커·속지처럼 만든 것마다 **플랫폼**과 **진행 상태**를 붙여 카드로 모읍니다. 카드마다 판매·정산 내역(날짜·판매 건수·수익 금액·메모)을 여러 건 쌓으면 **총 판매 건수·누적 수익**이 바로 다시 계산되고, 위의 **총 누적 수익·이번 달 수익·총 판매 건수**와 플랫폼별 수익 요약도 함께 따라갑니다. 플랫폼·상태 필터와 최신순·수익 높은순·이름순 정렬이 있고, **카드 | 달력**으로 보기를 바꾸면 출시·제출일(플랫폼 색 배지)과 그날 수익(+금액)을 월 달력으로 볼 수 있습니다(날짜 칸의 배지를 누르면 수정, +금액을 누르면 수익 내역). 플랫폼·상태 목록은 옆의 **🏷️ 분류 관리**에서 직접 추가·삭제하고 ⋮⋮로 순서를 바꿉니다.
- **카테고리 관리** — 상단 **카테고리** 버튼에서 형광펜·장부 분류·작업 플랫폼·**콘텐츠 플랫폼·콘텐츠 상태**·일정 분류·자기개발·여가 카테고리·식단 시간대·약 종류를 추가·이름 변경·삭제하고, 각 줄 왼쪽 **⋮⋮**를 끌어 **순서까지** 바꿀 수 있습니다(마우스·아이패드 터치·애플펜슬). 바꾼 순서·색은 카드·필터·달력에 그대로 반영되고, 이름을 바꾸면 그 이름을 쓰던 콘텐츠도 함께 따라갑니다. 지운 플랫폼·상태를 쓰던 콘텐츠는 다른 항목으로 옮기거나 표시만 지울 수 있고, 목록에 없는 이름도 회색 배지로 안전하게 보입니다.
- **D-DAY** — 디데이 하나를 상단에 고정.
- **인쇄 · PDF** — 지금 보이는 화면을 A4로 인쇄하거나 PDF로 저장.

## 클라우드 동기화 (Google 로그인 · 선택)

오른쪽 위 **Google 로그인** 버튼을 누르면 기록이 클라우드에 자동 저장되고, 다른 기기에서 열어도 같은 기록이 이어집니다.

- 로그인하지 않아도 모든 기능이 그대로 동작하며, 기록은 브라우저(`localStorage`)에 저장됩니다.
- 로그인한 상태에서는 변경 사항이 자동으로 올라가고, 다른 기기의 수정이 실시간으로 반영됩니다.
- 로그인하지 않은 상태에서는 클라우드 데이터를 **읽지도 쓰지도 않습니다**.
- 접근 권한은 서버(Firestore 보안 규칙)에서 판단하며, 허용되지 않은 계정으로 로그인하면 "접근 권한이 없는 계정입니다" 안내와 함께 자동으로 로그아웃됩니다.
- 로그아웃해도 이 기기의 기록은 지워지지 않습니다.
