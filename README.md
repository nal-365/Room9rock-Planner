# 방구석 작업실 · 올인원 플래너

일간 시간표 · 주간 목표 · 월간 리뷰 · 소비일지를 **한 장**에 담은 단일 HTML 플래너입니다.
빌드 도구 없이 `index.html` 하나로 동작하고, GitHub Pages에서 바로 열 수 있습니다.

> 🔗 https://nal-365.github.io/Room9rock-Planner/

## 무엇이 되나요

- **일간** — 10분 단위 24시간 타임트래커에 형광펜으로 시간을 칠하고, 할 일(일·공부·집안일)과 날씨·한 줄 메모를 적습니다. 작업·자기개발·일정·소비일지·여가 시간 열 아래에는 하루를 돌아보는 **피드백** 칸이 있습니다.
- **주간** — 이번 주 목표와 돌아보기, 요일별 시간 합계.
- **월간** — 달력 위에 하루 요약과 소비, 월 목표·리뷰.
- **소비일지** — 날짜·분류·메모·금액을 적으면 합계와 분류별 통계가 자동으로 나옵니다.
- **D-DAY** — 디데이 하나를 상단에 고정.
- **인쇄 · PDF** — 지금 보이는 화면을 A4로 인쇄하거나 PDF로 저장.

## 클라우드 동기화 (Google 로그인 · 선택)

오른쪽 위 **Google 로그인** 버튼을 누르면 기록이 클라우드에 자동 저장되고, 다른 기기에서 열어도 같은 기록이 이어집니다.

- 로그인하지 않아도 모든 기능이 그대로 동작하며, 기록은 브라우저(`localStorage`)에 저장됩니다.
- 로그인한 상태에서는 변경 사항이 자동으로 올라가고, 다른 기기의 수정이 실시간으로 반영됩니다.
- 로그인하지 않은 상태에서는 클라우드 데이터를 **읽지도 쓰지도 않습니다**.
- 접근 권한은 서버(Firestore 보안 규칙)에서 판단하며, 허용되지 않은 계정으로 로그인하면 "접근 권한이 없는 계정입니다" 안내와 함께 자동으로 로그아웃됩니다.
- 로그아웃해도 이 기기의 기록은 지워지지 않습니다.

## 열어 보기

```bash
# 로컬에서 바로
python3 -m http.server 8080
# → http://localhost:8080/
```

`index.html`을 더블클릭해 `file://`로 열어도 플래너는 정상 동작합니다(이때는 기기에만 저장).
